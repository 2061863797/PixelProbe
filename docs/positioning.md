# PixelProbe 定位与路线图

> 本文是 PixelProbe 2.0 起的功能取舍依据，取代本地的《时空表示生成引擎总体架构总结》。
> 数值语义仍以《PixelProbe 核心数据模型设计》为准；本文只决定"做什么、不做什么、按什么顺序做"。

## 一句话定位

**PixelProbe 专门补 AI 看图看视频的短板：AI 负责理解画面内容，PixelProbe 负责测量、定位和取证，给出能核实的数字。**

视觉语言模型擅长理解"画面里是什么"，但在以下方面不可靠：

- 准确说出事件发生在第几帧、第几毫秒；
- 读出准确的坐标、像素值和颜色；
- 察觉微弱变化、只在时间维度上存在的信号（单帧看像噪声，连续多帧才显现）；
- 计数（重复了几次、闪了几下）；
- 判断压缩、编码、元数据等取证线索。

PixelProbe 用确定性计算补上这些短板，并让每个数字都能追溯到帧号、时间、坐标和参数。

## 服务场景

| 场景 | 典型问题 |
|---|---|
| 开发者 UI 与录屏分析 | 按钮第几帧出现？动画持续了多少毫秒？有没有掉帧？两张截图哪里不一样？ |
| AI 看长视频的辅助 | 两小时的视频先看哪一段？这一段里发生变化的准确时刻和位置在哪？ |
| 视频质量与异常检测 | 有没有黑帧、冻结帧、闪烁、摩尔纹、模糊、压缩块？ |
| 图片与视频取证 | EXIF、压缩痕迹、噪声、C2PA 签名、重新编码迹象。只给证据，不下真伪结论 |

## 边界

**做**：时间定位、空间测量、数值统计、微弱信号显现、质量指标、取证证据，以及把这些结果整理成 AI 和人都容易看的形式（带刻度的图、标好时间的网格）。

**不做**：

- 理解画面语义、识别物体、OCR、语音转文字：交给 AI 自身；
- 剪辑、转码、生成、修图：交给 ffmpeg 或编辑工具；
- 自动判定"真/假"：只输出可复核的证据、参数、坐标和局限。

**取舍标准**：一个功能只有同时满足"AI 自己做不好"和"属于测量、定位或取证"两条，才加入。

## 三层分工

| 层 | 面向 | 原则 |
|---|---|---|
| 命令行 `pixelprobe` | 人与脚本 | 功能最全，覆盖全部分析能力 |
| MCP `pixelprobe-mcp` | AI | 能用到命令行的全部功能，但入口少（约 10 个工具），用参数选具体功能；结果大小受 AI 上下文预算控制 |
| 插件（Claude Code 与 Codex 共用） | AI | MCP 加上按场景编写的 Skill，教 AI 按"先粗后细"的顺序使用工具 |

三层共用同一套计算核心。每项功能在能力登记表中只定义一次，由对等测试保证 CLI 和 MCP 两侧都能用。

## 核心模型

视频被视为一个立方体 `V(x, y, t)`。任何一次分析都拆成四步：

1. **切**：选时间（帧、时间段）和位置（点、线、矩形、路径、网格格子）；
2. **量**：选取什么数值（颜色、亮度、运动、频谱……）；
3. **压**：选怎么汇总（平均、标准差、最大……）；
4. **出**：选输出给谁（原始数值、带刻度的预览、正式结果包）。

"切"由"时间选择 × 几何形状"自由组合，不再枚举固定类型。

### 统一地址写法

命令行与 MCP 共用，只使用英文符号。命令行已实现，完整规则见 [地址写法](address.md)：

```text
时间：  f=120 | f=100..200 | t=3.5s | t=12s..15s | t=all | step=5
空间：  point(520,340) | pid(n) | rect(x,y,w,h) | grid(x,y,w,h step=4) | row(y) | col(x)
        cell(C4) | cell(B2:C3) | cell(C4, 8x6) | line(x1,y1 -> x2,y2) | path(...)
引用：  @event3 | @seg2 | @region1
组合：  "t=12s..15s rect(400,200,200,150)"   "f=120 cell(C4)"   "@event3"
```

- `cell(C4)` 对应叠加在图上的网格，让 AI 用"格子名"代替难以估准的像素坐标；
- `@编号` 引用之前结果里的事件、分段、区域，避免 AI 手抄数字出错。

### 分层索引

同一个媒体只完整解码一次，生成：

| 层 | 内容 | 回答的问题 |
|---|---|---|
| L0 | 元数据 | 尺寸、帧率、时长、编码 |
| L1 | 每帧体检表（亮度、颜色、清晰度、帧间差异、指纹等） | 黑帧、冻结、闪烁、重复帧、镜头切换 |
| L2 | 分段 | 视频"目录"，AI 先看目录再决定看哪段 |
| L3 | 缩略立方体（每帧长边约 64 像素） | 快速出时空切片、变化热区、相似帧；定位后再回原视频精确计算 |

结果标注精度等级，并说明来自索引还是原始解码。

### 文件身份

- 日常查询用"快速指纹"（大小、修改时间、头尾内容哈希）确认文件没变，变化时索引作废；
- 导出正式结果包时计算完整 SHA-256 并写入溯源信息。快速指纹存在极小概率漏检，正式证据一律以完整哈希为准。
