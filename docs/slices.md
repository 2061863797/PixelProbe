# 2.0 新切法：差分切片、自适应时间轴、跟随切片

时空切片把"一条线上的像素随时间的变化"压成一张图：`xt` 取一整行（`row(y)`），`yt` 取一整列（`col(x)`），
纵轴是时间。2.0 新增三种切法，都与命令行、MCP（`pixelprobe_look view=xt/yt`、`pixelprobe_measure what=track`）共用。

## 差分切片：`--source diff`

每一行改为"该帧与上一展示帧在扫描线上的逐通道绝对差"。静止处为黑，运动、闪烁和细小变化变亮，
比原始切片更容易看出何时、何处在动。差分与切片可交换次序：结果与"先逐帧差分、再切片"逐值相同。

```powershell
pixelprobe xt "录屏.mp4" --at "t=2s..8s row(320)" --source diff --output 差分.png
```

- 第 0 帧没有前帧，不出现在结果中；
- 带 `step=n` 时仍与**上一展示帧**比较（不是上一采样行）。

## 自适应时间轴：`--time-axis adaptive --rows N`

按整帧变化量分配 N 行：每帧权重一半来自它的变化量（与上一帧的平均绝对差）占全段的比例、
一半均匀分布，按累计权重等分取帧，并总是保留首尾帧；单帧剧烈变化（如白闪）使多个等分点落在同一帧时，
在已选帧间隔最大处补帧，直到用满 N 行。变化多处取帧密、静止处疏，长视频压成一张图也不漏掉动作段。
行间时间间隔不均匀，以输出的 `frames` / `times`（MCP 图片纵轴刻度为帧号）为准；`sample_every` 为空。

```powershell
pixelprobe yt "长视频.mkv" --at "col(640)" --time-axis adaptive --rows 400 --output 自适应.png
```

变化量与索引 L1 的 `diff_prev` 同一定义。差分与自适应切片都只顺序解码一遍：解码时同时取每帧扫描线和
整帧变化量，只保留扫描线、不囤积整帧，结果与普通切片逐值相同（有回归测试）。
自适应时间轴由程序分配行数，地址中不能再写 `step=`。

## 跟随切片：`track`

从一个起点逐帧跟踪：在上一帧跟踪位置取 (2p+1)×(2p+1) 亮度块，在当前帧 ±search 像素内找平均绝对差最小的位置
（同分取位移最小）。整数像素精度，模板每帧更新，误差可能逐帧累积；最小误差超过 `lost_threshold`
即判定跟丢并停止（`lost_at`），不猜测后续位置。

```powershell
pixelprobe track "录屏.mp4" --at "f=120..300 point(512,240)" --follow-output 跟随.png --path-output 轨迹.png
```

输出：每帧 `x`、`y`、`dx`、`dy`、`cost`（匹配误差），总位移、路径长度、平均速度（像素/秒），
结果编号 `track_end`（终点的帧与坐标，可直接用作后续地址）。图片：

- `follow`：跟随切片，每帧在跟踪点所在行取以它为中心、宽 `strip_width` 的一段，被跟踪物体始终在中线上；
- `path`：首帧上画出轨迹（起点绿、终点红）。

适合测光标或控件的移动路径与速度、物体运动轨迹；画面大面积相似（纯色、重复纹理）时块匹配可能误配，
请查看 `cost` 和轨迹图复核。
